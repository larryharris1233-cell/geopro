# Hammer Lane Co app — fix list from Larry's hands-on test, Fri Oct 30, 2026

Reference benchmark (Larry, Oct 30): Smart Truck Route — match its
driver-facing features where our data allows (voice destination, speed-limit
display, IFTA mileage, satellite view, alt routes, stops on the way). We do
NOT copy their app or proprietary restriction data; routing stays Valhalla/OSM
and posted signs win.

Larry tested the installed Oct 16 build (Dallas TX search → Truck route → Start route)
and gave two required changes, both slated for the Nov 1 v2.1 build:

## 1. Start route must open LIVE MAP NAVIGATION, not the steps panel
Current behavior: tapping "Start route" replaces the map with a big turn-by-turn
steps card (Step 1 of 47, Back/Next buttons) covering most of the screen.
Wanted: tapping "Start route" starts real navigation ON the map — map stays
visible with the route line drawn, camera follows the truck's position, and the
current next-turn instruction shows as a slim banner (top or bottom), not a
full-screen steps list. The step list can stay available as an optional view,
but it must not be what Start route opens.
The navigation view must SHOW THE MILES while driving: miles left to the
destination, counting down live (Larry, Oct 30: "After I hit start route, I
would like for it to show the miles"). The readout is TAPPABLE and cycles:
miles left → ETA (arrival clock time) → time remaining (driving time left) →
back to miles (Larry: "If you hit the miles, I want it to show ETA" + "also
add time remaining"). Miles show by default; MPH stays in the slim bar.
ALSO: a SPEED LIMIT badge — a separate road-sign-style icon showing the
posted speed limit of the road he's on, next to the current MPH. Source the
limit from the route/road data (Valhalla/OSM maxspeed); where a road has no
limit data, hide the badge instead of guessing.

## 1b. "Start route" button right on the address-found card
On the card that appears after a successful address search (the one with Save /
Truck route / Add a stop), add a **Start route** button alongside Truck route.
Tapping it computes the best truck route and goes STRAIGHT into the live map
navigation of item 1 — no intermediate route-summary screen. Truck route keeps
its current behavior (summary with Best/Alt options) for drivers who want to
compare first.

## 2. Voice destination search (mic button)
Add a microphone button on the map screen. Tap it, say a place out loud
("Dallas Texas"), and the app puts that into the destination search and runs
the same search/geocode flow as typing it. Speech-to-text fills the search;
the driver confirms with the existing search/route buttons.

## 3. "Wrong exit, driver" screen — use Hammer Lane Co. branding
The not-found screen ("Wrong exit, driver. This screen doesn't exist.") shows a
stock fuzzy-character-at-a-laptop image. Replace that image with Hammer Lane
Co. branding (the app's truck icon art — deep-red long-nose rig on dark navy).
Keep the wording and the "Back to the map →" button as they are.
ALSO: Larry reports the app OPENED onto this screen. Opening the app must land
on the Map tab — check the initial route / any bad deep link or redirect that
sends a fresh open to the not-found screen, and fix the root cause if found.

## Phase 2 — Smart Truck Route feature parity (our own build, next build after Nov 1)
Larry named the settings/features he uses in Smart Truck Route and wants the
same capabilities in his app, implemented OUR way with our data (never their
code, screens, text, or proprietary data):
- **Route type settings:** fastest vs shortest route preference; avoid
  highways / avoid ferries where the router (Valhalla costing options)
  supports it.
- **Toll settings:** avoid-tolls toggle in routing; flag toll roads on a
  planned route.
- **Vehicle settings (expand My Truck):** height, weight, length, width, and
  hazmat class — height 13'6" / 80,000 lb stay the defaults.
- **Points of interest:** show ALL of Larry's named categories on the map —
  truck stops, rest areas, truck shops (repair), Walmarts — plus the existing
  fuel, weigh stations, and parking. Each category toggleable, browsable from
  the map and along a route. (Larry confirmed this list Oct 30.)
  ALSO: Truck Parking Club locations as their own parking layer — include
  their sites wherever they appear in our open data sources (OSM etc.).
  Their proprietary full location list / reservation system is NOT ours to
  extract; a real feed only if they offer a public API or partner program
  (check and report if that exists).
- **Spoken turn-by-turn:** voice guidance speaks each turn during live
  navigation (their app talks every turn; ours currently only alerts for
  weigh stations).
